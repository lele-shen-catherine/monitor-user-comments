# 监测对象配置

只在需要限定监测范围时读取。

| 类型 | 必需信息 | 样本边界 |
|---|---|---|
| `domain` | 领域名、关键词、同义词、排除词 | 只代表命中配置词的样本 |
| `topic` | 话题名、关键词、时间窗 | 只代表该话题的已采集样本 |
| `creator` | 达人 ID 或帖子链接、平台、范围 | “达人内容下评论”与“全平台讨论达人”分开分析 |
| `post` | 一个或多个帖子链接 | 只分析指定帖子 |

达人昵称可作辅助关键词，不能作为唯一身份标识。`owned_posts` 范围必须提供 `creator_id` 或 `post_url`；`platform_mentions` 范围按关键词匹配平台讨论。报告须记录对象类型、标识、关键词、排除词、平台、时间窗和数据批次。
